# The Undercurrent Ledger

Machine-readable memory for the closing long read. Extracted to
`state/undercurrent-ledger.json` by `tools/extract_state.py` and gated by
`tools/validate.py`.

**Why this file exists (editor, 4 Sep 2026 — reader-reported).** The Undercurrent
had been rotating by GEOGRAPHY only. The Issue Log receipts say things like
"Undercurrent Korea off Japan(86)" — which stops the same country running twice
in a row, and stops nothing else. So the same *subject* came back:

* **No. 68** ran India's astrology/faith-tech economy (AstroTalk). **No. 72** ran
  it again — same country, same company, four issues later.
* **No. 67** ran Vietnam's state-backed idol factory. **No. 75** ran Vietnam's
  survival-show idol economy.
* And a theme recurred under three different flags: the "buying certainty"
  story ran as India astrology (68, 72) and again as Thailand mutelu (84).

**THE RULE: geography rotation is necessary but not sufficient.** A subject
covered here is never covered again — the same once-only discipline the Hobby
Ledger applies to The Rabbit Hole. Adjacent-but-genuinely-distinct is fine
(Japan's plush companions and China's guzi are different scenes with different
communities); re-slicing the same scene under a new headline is not.
